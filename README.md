# XenhubV5

**Cleaned & Optimized Combined GUI** for Roblox.

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ideBob/XenhubV5/main/XenhubV5.lua"))()
```

## Features
- Modular UI system
- Theme-driven design
- Settings panel with tabs (Keybinds, Auto TP, ESP, UI, Misc, Priority, Performance)
- Movement Panel
- Steal Panel
- Actions Panel
- Admin / Proximity Panel
- Command Cooldowns
- FPS / Ping display
- Fully draggable panels
- RightShift to toggle UI visibility
- LeftControl to open Settings
